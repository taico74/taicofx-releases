# TaicoFX

Extension After Effects (Windows) pour accélérer les montages gaming et TikTok.

Ce dépôt héberge uniquement les **mises à jour** de l'extension (fichiers de version téléchargés automatiquement par le panneau). Il ne contient pas le code source.

## Ce que fait TaicoFX

- **Presets** — bibliothèque de tes presets `.ffx` et `.aep` avec recherche, favoris, vignettes et aperçus vidéo.
- **Flow** — éditeur de courbes d'easing, import des bibliothèques `.flow`, calage sur la grille.
- **Texte** — ancrage, animations en un clic, presets texte perso avec auto-fit.
- **Beat & Paroles** — marqueurs sur les claps, et un marqueur par mot chanté (reconnaissance vocale 100 % locale).
- **Shake** — Shake Zoom en un clic et navigateur de shakes Motion Bro / HST calés sur les beats.
- **Sync** — kills calés sur les beats façon Valorant, profils de couteaux et time remap par couteau.

## Installation

L'extension s'installe depuis le pack livré à l'achat (`install.bat`), pas depuis ce dépôt.

## Mises à jour

TaicoFX vérifie automatiquement les nouvelles versions au lancement d'After Effects et propose de les installer. Après installation, redémarre complètement After Effects.
